## 🚀 How to Start (Right Now)

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Edit Configuration
Open `config.py` and update:
- `ADMIN_CHAT_ID` = Your Telegram ID (get from @userinfobot)
- `BOOKING_URL` = Your Calendly link
- `WEBSITE_URL` = Your website
- `WHATSAPP_URL` = Your WhatsApp link
- `EMAIL` = Your email
- Content text blocks (ABOUT_TEXT, SERVICES_TEXT, etc.)

### Step 3: Run the Bot
```bash
python main.py
```

### Step 4: Test in Telegram
- Find your bot
- Send `/start`
- Click all buttons
- Submit a test form
